Dutch Bum Simulator — браузерная PWA демо 0.1.

Для запуска на iPhone нужен HTTPS-хостинг. Бесплатный вариант — GitHub Pages:
1. Создайте публичный репозиторий GitHub.
2. Загрузите в корень репозитория все 5 файлов из этой папки (не ZIP).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Дождитесь появления URL вида https://USERNAME.github.io/REPOSITORY/.
5. Откройте его в Safari на iPhone → Поделиться → На экран «Домой».

Для теста на Windows можно открыть index.html в браузере. Установка PWA и офлайн-режим требуют HTTPS.
Прогресс сохраняется только в браузере текущего устройства. Синхронизации между устройствами пока нет.
